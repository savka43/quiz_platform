# Импорт тестов из PDF через JSON

## Что умеет PDF-парсер

PDF-парсер надёжнее всего разбирает текстовый PDF, где каждый вопрос начинается с номера, варианты находятся после `Варианты ответа:`, а ключ записан после `Ответ:`. Текст должен извлекаться из PDF — сканы без текстового слоя требуют OCR и напрямую не разбираются.

Готовый одностраничный образец можно открыть здесь: [`quiz-import-format-sample.pdf`](../output/pdf/quiz-import-format-sample.pdf).

Рекомендуемый вид исходного текста:

```text
Название теста: Основы HTTP

1. Какой HTTP-код означает, что страница не найдена?
Варианты ответа:
1. 200 - Запрос выполнен успешно
2. 404 - Страница не найдена
3. 500 - Внутренняя ошибка сервера
Ответ: 404 - Страница не найдена
Пояснение: Сервер не нашёл ресурс по указанному адресу.

2. Какие из этих значений являются чётными?
Варианты ответа:
1. 2
2. 3
3. 4
Ответ: 2; 4

После ответа последнего вопроса не добавляй колонтитулы или текст, который может быть принят за ответ.
```

Если PDF устроен иначе, попроси ИИ преобразовать его в JSON по инструкции ниже, сохрани результат как `.json` и загрузи этот файл в приложение. JSON-парсер показывает те же превью, позволяет исправить формулировки и ключи и только после подтверждения сохраняет тест.

## Формат JSON

Корень файла — объект `title`, `description` и `questions`. Поддерживаются типы `single_choice`, `multiple_choice`, `text`, `fill_blank`, `matching`. Пример для каждого типа есть в [`src/public/quiz-import-example.json`](../src/public/quiz-import-example.json).

У вариантов `is_correct` должен быть `true` или `false`. Если источник не сообщает правильный ответ, поставь `null`: превью попросит проверить его вручную. Не угадывай ответ по частоте голосов, выделению текста или выбранной радиокнопке. Для свободного ответа укажи `correct_answer`. Для пропусков и сопоставления заполни `blanks`; у каждой строки нужны `prompt` и `correct_answer`, у сопоставления также `choices`.

Можно загрузить JSON-объект и без необязательных пустых полей. Например, для одного вопроса:

```json
{
  "title": "Основы HTTP",
  "questions": [
    {
      "text": "Какой HTTP-код означает, что страница не найдена?",
      "question_type": "single_choice",
      "options": [
        { "text": "200", "is_correct": false },
        { "text": "404", "is_correct": true },
        { "text": "500", "is_correct": false }
      ]
    }
  ]
}
```

## Запрос к ИИ для преобразования PDF

Прикрепи PDF и отправь ИИ этот запрос:

> Преобразуй все вопросы из прикреплённого PDF в JSON по формату из примера. Сохрани название теста, полный текст вопросов, все варианты в исходном порядке, пояснения и правильные ответы только если они явно указаны в документе. Не додумывай отсутствующие ответы: ставь `is_correct: null` и оставляй `correct_answer` пустым. Для вопроса с несколькими правильными вариантами используй `multiple_choice`; для одного — `single_choice`; для короткого текстового ответа — `text`; для пропусков — `fill_blank`; для сопоставления — `matching`. Верни один корректный JSON-объект без Markdown-ограждений и пояснений. Структура: `{ "title": "...", "description": "...", "questions": [{ "text": "...", "question_type": "single_choice", "options": [{ "text": "...", "is_correct": true }] }] }`. Не пропускай вопросы. Если документ обрезан или вопрос разобрать нельзя, включи его с максимально точным текстом и добавь проблему в `warnings`.

Ответ ИИ сохрани в файл с расширением `.json`. Перед сохранением теста проверь варианты со знаком `?` и предупреждения в превью.
