## Реальные исходные файлы

HTTP-проверка использовала локальный Docker API и предоставленные пользователем файлы. Файлы не включены в репозиторий.

| Источник | Найдено вопросов | Требуют проверки | Сохранено и пройдено автоматически |
| --- | ---: | ---: | ---: |
| PMiS (1).pdf | 124 | 23 | 101 |
| ВопросыНовые - SyncShare.html | 70 | 66 | 4 |

Для однозначно распознанных вопросов выполнена цепочка: регистрация → вход → preview → правка текста → confirm → старт → ответы → завершение → результат 100% → отсутствие ошибок → удаление источника → сохранность результата → refresh → logout. Временные данные удаляются скриптом.

Этот сценарий проверяет согласованность API и подсчёта с извлечёнными ключами, а не независимую предметную правильность каждого ответа. Неоднозначные или отсутствующие ключи требуют ручного исправления в превью; статистика голосов не превращается в правильный ответ.

Повторить из `backend/` при запущенном локальном API:

```bash
uv run python scripts/smoke_imports.py --pdf '/path/test.pdf' --html '/path/test.html'
```

## Границы готовности

Backend MVP предоставляет API для согласованных сценариев. Визуальное редактирование превью и остальные экраны требуют frontend. OCR, другие форматы источников, восстановление пароля и публичное развёртывание не входят в проверенный объём.
