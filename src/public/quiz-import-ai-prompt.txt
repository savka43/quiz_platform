Преобразуй все вопросы из прикреплённого PDF или HTML в JSON по формату из приложенного примера.

Сохрани название теста, полный текст каждого вопроса, все варианты в исходном порядке, пояснения и правильные ответы только если они явно указаны в документе. Не угадывай ключи: если источник не сообщает правильность варианта, ставь "is_correct": null. Не считай выбранную радиокнопку, цвет, статистику или популярность ответа доказательством правильности.

Используй типы single_choice (один правильный вариант), multiple_choice (несколько), text (короткий текстовый ответ), fill_blank (пропуски) и matching (сопоставление). Для вариантов укажи массив options из объектов {"text":"...","is_correct":true|false|null}. Для текстового ответа используй correct_answer. Для fill_blank и matching используй blanks: объекты с prompt, correct_answer и choices. У matching choices содержит варианты для строки.

Верни один корректный JSON-объект без Markdown-ограждений и пояснений. Формат корня: {"title":"...","description":"...","questions":[{"text":"...","question_type":"single_choice","options":[{"text":"...","is_correct":true}],"correct_answer":"","blanks":[],"explanation":""}]}. Не пропускай вопросы. Если страница обрезана или распознать её нельзя, сохрани доступный текст и добавь причину в warnings.
