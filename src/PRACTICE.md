# День 3 — прохождение тестов

## Что работает

- «Начать тест» в карточке создаёт попытку и открывает `/attempts/:attemptId`. Повторные клики блокируются на время запроса.
- Вопросы загружаются из снимка попытки без правильных ответов. Поддерживаются один вариант, несколько вариантов, текст, пропуски и сопоставление.
- «Сохранить ответ» записывает ответ в БД; «Сохранить и дальше» делает запись перед переходом. Если запрос не удался, переход не выполняется и введённый ответ остаётся на странице.
- Кнопки номеров и «Назад» позволяют переключаться между вопросами, сохраняя локальный ввод в памяти. Эти переходы сами по себе не отправляют ответы на сервер.
- Прогресс показывает количество вопросов с ответами в БД. Изменение ранее сохранённого ответа нужно сохранить повторно; подпись под текущим вопросом показывает состояние.
- При обновлении страницы восстанавливаются **сохранённые** ответы. Текущий номер вопроса находится в `?q=`. Перед перезагрузкой с локальными изменениями браузер предупреждает о возможной потере ввода.
- На главной есть ссылки на незавершённые попытки. Они позволяют продолжить уже начатый тест, не создавая новую попытку.
- Завершение проверяет все ответы, сохраняет изменения и вызывает серверный подсчёт. Незаполненный вопрос открывается с сообщением. После завершения ввод недоступен, показываются балл и число правильных ответов.
- При повторном открытии завершённой попытки сразу загружается итог. Ответы не пересчитываются на клиенте.

Подробный разбор ошибок, история завершённых попыток и избранное относятся к следующим дням и в этот этап не входят.

## API

Добавлен `GET /api/v1/attempts/{attempt_id}/answers`: только владелец получает сохранённые ответы выбранной попытки. До завершения `is_correct = null`. Структура БД не менялась, миграция не нужна.
